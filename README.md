# fizzbuzz

Простой скрипт FizzBuzz на Python.

## Использование

```bash
python fizzbuzz.py
python fizzbuzz.py 30
```

Без аргументов печатает результат `fizzbuzz(15)` построчно. Можно указать
положительное целое число `N`, чтобы получить строки от 1 до `N`.
Некорректный аргумент приводит к сообщению об ошибке и ненулевому коду выхода.
Числа, кратные 3, заменены на `Fizz`, кратные 5 — на `Buzz`,
кратные 15 — на `FizzBuzz`.

## API

`fizzbuzz(n)` — возвращает список строк по правилам FizzBuzz для чисел `1..n`.
