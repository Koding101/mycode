# fizzbuzz

Простой скрипт FizzBuzz на Python.

## Использование

```bash
python fizzbuzz.py
```

Печатает результат `fizzbuzz(15)` построчно: числа от 1 до 15, где кратные 3
заменены на `Fizz`, кратные 5 — на `Buzz`, кратные 15 — на `FizzBuzz`.

## API

`fizzbuzz(n)` — возвращает список строк по правилам FizzBuzz для чисел `1..n`.
